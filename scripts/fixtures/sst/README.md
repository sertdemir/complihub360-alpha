# SST-Rate-Files — echter Auszug

Aufgezeichnet am 17.09.2026 von
`https://www.streamlinedsalestax.org/ratesandboundry/Rates/` (24 Mitgliedsstaaten,
zusammen 5,6 MB). Hier steht je Staat ein **Auszug aus der echten Datei**:

- **alle** Zeilen mit Jurisdiction Type 45 — auch die historischen, denn an ihnen
  haengt die Stichtagslogik (Ohio traegt seine Staatssaetze zurueck bis 1979)
- die ersten sechs lokalen Zeilen, damit der Komposit-Fall (Nevada) und die
  Zaehlung der Jurisdiktionen etwas zu sehen bekommen

Nichts ist umgeschrieben. Die gepackten Dateien sind ausgepackt abgelegt, damit
die Fixture lesbar bleibt; der ZIP-Pfad im Skript wird gegen die Live-Quelle
geprueft, nicht hier.

**Die Zahlen sind keine Datenquelle.** Wer einen Satz braucht, holt ihn beim
Staat, nicht aus einer Testdatei.
